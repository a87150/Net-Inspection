# 简化人员 API 导入与后台通知设计

## 目标

将现有多来源人员目录功能收缩为两套固定配置：飞书和钉钉。用户只需保存 API 凭据，依次完成测试连接、预览数据和导入数据。测试和预览在后台 Worker 中执行，页面不再通过自动刷新闪烁；任务结束后使用弹窗通知并提供结果跳转。

同时修复 PC 分析配置弹窗的可用性，使配置正文在弹窗内可上下滚动，并保留底部保存按钮。

## 范围

本次包含：

- 飞书、钉钉固定配置表单；
- API 凭据保存与替换；
- 连接测试、数据预览、确认导入；
- 后台任务运行提示、关闭提示、完成弹窗和结果跳转；
- 预览数据的校验失败展示；
- PC 分析配置弹窗内部滚动。

本次不包含：

- 任意数量的人员目录来源；
- 来源名称、稳定来源标识或来源选择器；
- 自动定时同步人员；
- 后台任务完成后的飞书、钉钉或邮件告警；
- 对旧多来源配置提供兼容界面或自动迁移。

## 配置模型

继续使用 `PeopleSyncSource` 作为内部存储，避免新增模型和数据库迁移。页面和 HTTP 接口不再暴露“来源”概念。

每个平台使用固定内部标识：

- 飞书：`source_type=feishu`，`source_key=people-provider-feishu`，内部名称固定为“飞书”；
- 钉钉：`source_type=dingtalk`，`source_key=people-provider-dingtalk`，内部名称固定为“钉钉”。

保存配置时按固定 `source_key` 执行 `update_or_create`。用户只能提交平台所需凭据、根部门和启用状态，不能提交名称或标识。密码字段始终只写：编辑时留空表示保留，填写表示替换。旧的自定义来源记录不在页面展示，也不参与新的固定流程。

## 页面流程

人员列表的“导入人员”弹窗保留“文件、飞书、钉钉”三个页签。

飞书和钉钉页签分别展示：

1. API 配置表单和“保存设置”；
2. “测试连接”按钮；
3. “预览数据”按钮。

未保存配置时，测试和预览按钮禁用。当前配置尚未测试成功，或测试后又修改了配置时，预览按钮禁用。

操作顺序固定为：

1. 保存设置；
2. 测试连接；
3. 预览数据；
4. 查看预览；
5. 导入数据。

预览结果页面显示新增、更新、不变、停用和跳过数量，并显示有限数量的样例。只有预览有效且具有签名令牌时才显示“导入数据”。预览无效时只显示校验原因，不允许导入。

人员仍以工号作为唯一匹配键。CSV 和手工人员可以按工号被当前 API 配置更新并纳入同步；已属于另一 API 配置的人员不可被接管。没有工号的远端记录被跳过并计数，不阻止其他正常人员导入。字段格式错误、重复工号或受保护来源冲突会令整个预览失败。

导入使用当前已签名预览执行一次数据库事务。成功后跳转人员列表并显示新增、更新、停用数量；失败时不进行部分写入，并返回预览结果页面显示失败原因。

## 后台任务与通知

测试连接和预览数据继续由独立 Worker 执行。创建任务后立即重定向回当前平台的导入页签，不进入持续自动刷新的任务页面。

当前浏览器会话记录自己创建的人员目录任务。页面显示一条轻量运行提示，例如“飞书预览正在后台运行”。用户点击“知道了，本次不再显示”后，该任务的运行提示在当前会话中不再出现，但任务继续执行。

人员导入页面通过轻量 JSON 状态接口轮询当前会话尚未结束的任务，不刷新整个页面。任务变为成功或失败时打开一次 Bootstrap 完成弹窗：

- 连接测试成功：提示成功，跳转按钮返回对应平台页签，此时预览按钮已启用；
- 预览成功：提示成功，跳转按钮进入预览结果页面；
- 失败：显示安全、明确的阶段错误，跳转按钮进入结果页面查看详情。

完成弹窗被确认或点击跳转后，前端调用确认接口，当前会话不再重复显示该任务。轮询只返回当前会话创建的任务，不暴露其他会话任务。

移除人员操作响应中的 `Refresh` 自动刷新头。JavaScript 请求失败时停止本轮轮询，不影响页面其余功能；用户重新打开导入弹窗时可恢复查询。

## 错误处理

配置表单直接显示缺失字段、格式错误和重复固定标识等校验信息，但不得回显或写入会话中的 API 密钥。

Worker 将错误划分为认证失败、权限不足、请求频率限制、接口连接失败、响应格式错误和预览数据校验失败。面向页面的消息不得包含访问令牌、Secret、完整请求 URL 或人员敏感内容。

连接测试必须验证令牌、根部门人员接口和子部门接口。预览必须完整遍历目录并成功生成签名令牌；否则状态为失败。

## PC 分析配置弹窗

`#profileConfigModal` 使用受视口高度约束的弹窗内容区。标题栏和底部操作栏保持可见，`.modal-body` 独立设置 `overflow-y: auto` 和适当的最大高度，使鼠标滚轮、触控板和键盘均可上下浏览全部配置项。

只保留底部“取消”和“保存配置”按钮，不在顶部重复保存按钮。小屏幕下按钮继续纵向排列。

## 测试

后端测试覆盖：

- 页面只展示飞书和钉钉固定配置，不出现新建来源、来源名称、稳定标识和来源选择器；
- 凭据新增、留空保留和填写替换；
- 测试成功后才能预览；
- 后台任务仅属于创建它的浏览器会话；
- 状态轮询、运行提示关闭和完成确认；
- 有效预览显示导入按钮，无效预览禁止导入并显示原因；
- CSV/手工人员按工号接管，其他 API 人员保持保护；
- 导入事务成功和失败回滚。

前端测试覆盖：

- 轮询不触发整页刷新；
- 运行提示可按任务关闭；
- 完成弹窗只显示一次并使用正确跳转地址；
- PC 分析配置正文具备独立纵向滚动区域，底部保存按钮存在。

最终验证仅运行人员目录、任务通知、PC 配置页面相关测试和 Django 系统检查，不执行真实人员导入。
