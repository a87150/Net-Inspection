# 综合运维展示、逻辑拓扑与移动端优化设计

## 目标与边界

在现有 Django、Bootstrap 和 CSS 技术栈内新增只读“综合展示”页面，在同一页面切换“运维态势”和“网络拓扑”。该页面允许单独使用 Vue 3 管理复杂的实时状态与拓扑交互；普通后台继续使用现有模板和原生 JavaScript。页面使用独立的深色科技风视觉，但不改变普通后台的毛玻璃设计系统，也不引入在线资源。

同时调整现有入口：

- 顶部 PC 菜单按“PC 列表、日志列表、日志分析记录”排列。
- 日志分析记录页删除“导入日志证据 / 重新分析”按钮；首页 PC 卡片在“PC列表”旁增加“日志列表”。
- PC 日志列表的“分析筛选结果”进入公共筛选操作区，紧邻“导出筛选结果”；分析弹窗和任务逻辑不变。
- 巡查主要页面的移动端布局，只修复模板、CSS 和现有原生 JavaScript；Vue 仅用于综合展示页，不改变模型、任务、告警、导入或巡检流程。

## 页面、路由与权限

新增两个认证只读入口：

- GET /operations/overview/，路由名 operations_overview，渲染页面外壳和首屏安全数据。
- GET /operations/overview/data/，路由名 operations_overview_data，返回局部刷新 JSON。

顶部导航在“告警记录”左侧增加“综合展示”。现有普通用户、管理员和超级管理员按原只读权限查看；接口无写操作，不返回密码、Webhook、SNMP/SSH 密钥、域控凭据或未脱敏原始输出。

展示适配器、模板、CSS 和 Vue 应用独立组织。Vue 3 的生产版 ESM 文件作为本地静态资源随项目部署，不从 CDN 加载；应用只挂载综合展示根节点，不接管公共导航、确认框或其它后台页面。深色主题同样仅在该根节点内生效。

## 运维态势视图

页面顶部显示标题、当前时间、最后成功更新时间、数据新鲜度、双视图切换、立即刷新、暂停刷新和状态图例。

运维态势包括：

1. 全局指标：资产总量、正常、异常、未巡检、运行中任务、失败任务和未处理告警。
2. 资产矩阵：人员、PC、网络设备、服务器、安防设备和域控对象的总数及状态，并提供现有页面入口。
3. 健康分布：原生 SVG 环图或条形图，同时保留文字和数值。
4. 任务活动：最近运行、成功、失败和取消任务的时间线。
5. 告警流：严重级别、对象、时间、事件状态及按结果合并的渠道送达状态。
6. 异常概览：最近异常类别、数量和异常记录入口。

数据复用现有资产汇总、任务摘要、异常和告警查询。展示适配器只进行安全字段选择与只读聚合。

## 网络拓扑视图

第一阶段展示逻辑拓扑：

- 根节点为运维管理台，第二层按网络设备、服务器、PC、安防设备和域控分组。
- 网络设备可按设备类型或 IP 网段继续聚合。
- 节点展示名称、地址、类型和状态，点击后打开摘要及现有详情入口。
- 逻辑关系使用虚线并明确标注“逻辑归属”，不能冒充物理链路。
- 不根据同网段、ARP、MAC/FDB 或相同 VLAN 生成物理连线。

后端现已提供 LLDP/CDP 数据；同一视图优先显示明确标记为 physical_discovered 的真实链路。物理链路使用实线，展示协议来源、接口端点、状态、速率、VLAN、可信度和采集时间。单侧、双向确认、陈旧与冲突证据必须有不同文字和线型，不能只依靠颜色。已解析远端连接现有设备节点；未解析远端保留为带“未解析邻居”文字的外部节点，不丢弃证据，也不把名称辅助匹配冒充为已确认端点。

拓扑由页面级 Vue 组件渲染原生 SVG，支持拖动、缩放、适应屏幕、重置、筛选、节点或链路详情、键盘聚焦和等价文本列表。桌面使用侧边详情面板，移动端使用底部抽屉。

## 数据和自动刷新

只读 JSON 结构包含：

- meta：生成时间、新鲜度、局限说明和区域错误。
- summary：全局指标和资产摘要。
- tasks：最近任务安全摘要。
- alerts：最近告警及渠道结果。
- issues：最近异常聚合。
- topology：逻辑节点、分组及可选物理节点和链路。

页面默认每 30 秒局部刷新，不整页跳转，并保留当前视图、筛选、缩放与暂停状态。页面隐藏时暂停，重新可见时立即刷新；手动暂停后不得自动恢复。使用请求超时和单飞控制，离开页面时取消未完成请求。

失败时保留最后一次成功数据，显示失败区域和最后成功时间；单一区域失败不阻断其他区域。空数据使用明确空状态，不生成演示数字、虚构设备或虚构链路。

## 科技风视觉与动效

- 深蓝黑渐变、细网格、低透明扫描线、局部辉光与轻量噪点。
- 正常为荧光青绿、信息为青蓝、警告为琥珀、严重异常为红、未知为灰蓝；始终配套文字或图形。
- 数字首次加载短时递增；物理链路使用低频流光；异常节点使用克制脉冲。
- Vue 页面内的轻量 Canvas 控制器可绘制装饰性粒子或网络点阵，并设置 aria-hidden。

动效尊重 prefers-reduced-motion；页面隐藏时停止动画和刷新；移动端降低粒子密度及频率。不得高频闪烁、遮挡内容或影响键盘和屏幕阅读器。全部资源随项目部署，Windows 和 Linux 均无需联网。

## PC 导航、首页卡片和日志工具栏

顶部 PC 菜单固定为：

1. PC 列表
2. 日志列表
3. 日志分析记录

首页 PC 卡片次要动作按“PC列表、日志列表、日志分析记录”排列，主要动作“手动执行分析”不变。日志分析记录页删除旧日志入口，不增加替代按钮；用户从顶部菜单或首页 PC 卡片进入日志列表。

公共表格工具栏增加可选的页面专属动作插槽。PC 日志列表用该插槽将“分析筛选结果”放在“导出筛选结果”之后，保留现有筛选参数和 bulk_mode=filtered。批量分析弹窗仍位于查询表单之外，避免嵌套表单。其他表格未使用插槽时 HTML 和行为不变。

## 移动端适配巡查

验证 360px、390px、768px、1024px 和宽屏桌面。覆盖首页、资产列表与详情、PC 日志和分析、巡检记录、任务、告警、域控、人员导入、设备导入及主要配置弹窗。

重点修复：

- 顶部导航折叠、下拉滚动和账号菜单可达性。
- 标题、说明和操作按钮在窄屏纵向排列，不重叠或截断。
- 筛选字段和动作使用可用宽度，导出与专属动作顺序稳定。
- 表格保留语义与横向滚动；移动端取消固定操作列遮挡。
- 长文本、状态标签和按钮组可换行。
- 弹窗只保留一个正文滚动区域，标题和底部操作可见。
- 触控目标达到基本尺寸，焦点清晰。
- 综合展示移动端为单列信息流；拓扑保持可拖动视口并提供等价节点列表。

若问题源自后端数据或业务流程，只记录并移交，不在本前端任务中修改。

## 后端真实拓扑数据契约

后端已实现巡检驱动的 LLDP/CDP 采集、持久化和只读查询：

- 拓扑发现批次：来源任务、协议、状态、采集时间和版本。
- 本地接口：设备、稳定接口键、名称、描述、MAC、管理/运行状态、速率、VLAN、首次与最后发现时间。
- 当前链路：本地和远端端点、远端 chassis/port/system/管理地址、协议来源、单侧或双向证据、状态、速率、VLAN、可信度和采集时间。
- 不可变观察证据：发现批次、已脱敏且限长的 SNMP/SSH 证据、摘要哈希和来源巡检。
- 认证只读 API：/operations/topology/ 返回接口与当前链路白名单字段；批次、接口和链路有分页端点；原始证据使用单独权限接口。

只有 LLDP/CDP 明确证据可生成物理链路。名称仅辅助匹配，冲突时保持未解析节点；连续未发现的链路标为陈旧而非立即删除。建议使用 30–60 分钟的独立低频拓扑采集配置。

后端采集仍不属于本前端实施计划。前端综合快照直接复用 net.topology.read_model.current_topology_payload() 的白名单结构，不重复序列化原始证据，也不从服务器内部发起 HTTP 自调用。没有物理数据时自然降级为逻辑拓扑。

## 安全与可访问性

- 页面和接口沿用现有认证与只读权限。
- JSON 显式白名单序列化，禁止返回秘密或未脱敏异常文本。
- 动态文本通过 Vue 默认文本转义渲染；禁止使用 v-html 或 innerHTML 拼接服务器数据。
- 状态同时使用文字、形状和颜色；焦点、标题、标签和键盘操作满足基本可访问性。
- Canvas 只负责装饰；核心图表与拓扑信息存在于 SVG 或等价文本列表。
- 自动刷新 live region 不在每次刷新时朗读整页。

## 测试和验证

实现遵循测试驱动：

1. 先添加失败测试，覆盖导航顺序、首页 PC 入口、日志分析页按钮移除和日志工具栏动作位置。
2. 覆盖综合展示权限、字段白名单、部分失败、空状态和敏感信息排除。
3. Vue 状态与拓扑布局逻辑拆分为可测试模块，Node 测试覆盖双视图、30 秒刷新、暂停、页面可见性、请求单飞、旧数据保留、减少动态效果和拓扑交互。
4. 使用本地浏览器执行 Vue 挂载、刷新、视图切换和响应式集成检查，并验证 360px 至宽屏目标宽度。
5. 运行相关 Django 测试、全部 Node 前端测试、模板加载、manage.py check、迁移漂移检查和 git diff --check。

测试只使用隔离数据库、mock 和 fixture，不访问真实飞书、钉钉、域控或设备，不执行真实导入、巡检、SNMP、SSH、LLDP 或 CDP 请求。

## 非目标

- 本阶段不新增或修改拓扑、接口或链路数据库模型。
- 不实现真实 LLDP/CDP 采集、自动发现、配置下发或网络变更。
- 不伪造物理链路。
- 不替换现有首页、列表、详情、巡检、告警或管理后台。
- 不在综合展示页之外引入 Vue，不引入 React、其它大型前端框架、在线图表库、在线字体、图片或图标。
