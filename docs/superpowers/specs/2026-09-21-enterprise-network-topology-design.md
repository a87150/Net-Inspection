# 企业网络拓扑交互设计

## 目标

将现有按 IP 网段平铺的拓扑改为符合企业网络结构的分层拓扑。默认聚焦防火墙、路由器、交换机和无线 AC 等主干网络设备；操作人员点击主设备后，再查看其下联的 PC、服务器、AP 和安防设备。

正式环境只展示真实资产和采集数据。模拟企业拓扑只写入 `deploy.demo` 的隔离演示数据库，不作为正式环境的回退数据。

## 范围

- 保留现有网络拓扑页面路由、刷新、缩放、拖动、链路详情和无障碍文字列表。
- 保留 LLDP/CDP 采集、存储和读取流程，不修改设备巡检逻辑。
- 不增加数据库模型或迁移。
- 不把域账号、域计算机、域分组或人员放入拓扑。
- 不在正式数据库中自动创建模拟设备。

## 设备分类

主干设备包括：

- 防火墙、安全网关和出口网关；
- 路由器；
- 核心、汇聚和接入交换机；
- 无线 AC。

可展开终端包括：

- PC；
- 服务器；
- AP；
- 摄像头、门禁等安防设备；
- 不能识别为主干类型的其他边缘设备。

设备类型识别使用现有 `device_type`、名称、厂商和连接类型字段进行规范化，未知类型保持明确的“其他网络设备”标识，不凭空改变资产类型。

## 数据与关系

### 主干链路

主干设备之间仅使用 `NetworkTopologyLink` 中 LLDP/CDP 实际发现的链路。双向发现记录在前端归并为一条链路，但保留协议、接口、速率、VLAN、置信度和最后发现时间。

没有被解析到现有资产的 LLDP/CDP 邻居继续显示为“未解析邻居”，不会生成虚假的正式设备。

### 终端归属

终端归属按以下优先级确定：

1. 已采集并能解析到主干设备的物理关系；
2. 与接入交换机或 AC 位于同一明确 IP 网段；
3. 与汇聚或核心交换机位于同一明确 IP 网段；
4. 无法归属时进入“未归属终端”集合，不随机连接。

同一优先级存在多个候选时，使用设备类型优先级和稳定主键排序进行确定性选择，确保刷新后连接关系不跳动。由网段推断的连接必须标记为 `inferred_subnet`，不得显示为 LLDP/CDP 实际发现。

### 页面数据

现有拓扑数据接口地址不变。响应中的拓扑区域提供：

- 主干节点及其层级角色；
- 实际物理主干链路；
- 每个主干节点的终端摘要；
- 可按需展开的终端节点和归属边；
- 关系来源（物理发现或网段推断）；
- 截断数量和不可用状态。

页面首次加载收到完整的安全展示数据，但默认只渲染主干节点。点击展开属于纯前端状态，不写数据库、不触发设备接口。

## 交互与视觉

拓扑采用自上而下的分层布局：出口/防火墙、核心、汇聚、接入与 AC。终端展开后排列在对应主设备下方或侧下方。

主干节点使用设备卡片形态，至少显示设备类型、名称、管理 IP、厂商、状态和下联终端数量。节点类型通过图形、文字和颜色共同表达，不能只依赖颜色。

链路规则：

- LLDP/CDP 主干链路：较粗实线；
- 陈旧的物理链路：低饱和实线并带“陈旧”文字状态；
- 网段推断终端连接：较细虚线并标记“网段推断”；
- 选中链路：显示协议、两端接口、速率、VLAN、置信度和最后发现时间。

主设备显示“展开 N 个终端”提示和数量徽标。点击或键盘 Enter/Space 可展开、收起。展开状态在刷新数据后按仍存在的设备 ID 保留，在离开页面后清除。

移动端保持画布缩放和拖动，工具栏换行，不产生页面级横向滚动。提供等价文字树列表，保证键盘用户和屏幕阅读器能够访问相同信息。

## 演示数据

`seed_demo_data` 在隔离演示库中生成一套确定性的企业网络：

- 双出口防火墙；
- 两台核心交换机；
- 办公网、服务器区和安防区的汇聚/接入交换机；
- 无线 AC 与若干 AP；
- 分属办公网、服务器区、无线网和安防网的 PC、服务器、摄像头及门禁设备；
- 能构成主干结构的 LLDP/CDP 接口与链路记录。

种子必须幂等；重复执行不新增重复资产或链路。现有非空正式资产表不会因为页面访问而被填充模拟数据。

## 空状态和异常处理

- 没有主干设备：显示“暂无可绘制的主要网络设备”，并提供网络设备列表入口。
- 有主干设备但无 LLDP/CDP：显示主设备分组和“尚未采集物理链路”提示，不伪造主干连接。
- 单个数据区域查询失败：页面显示该区域不可用，保留最近一次成功快照。
- 节点数量超过展示限制：优先保留所有物理链路端点，明确显示省略数量。

## 验证

- 后端测试覆盖设备分类、分层角色、真实链路、稳定的终端归属、未知类型、空状态、截断和数据库异常。
- 前端测试覆盖默认只显示主干、点击展开/收起、刷新后保留有效展开状态、链路样式来源、键盘操作和稳定分层布局。
- 演示种子测试覆盖设备和链路数量、幂等性及重置行为。
- 浏览器验证覆盖桌面端和移动端，无横向溢出、主干默认视图正确、展开交互正常且没有控制台错误。
