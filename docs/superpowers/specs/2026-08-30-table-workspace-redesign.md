# 网络巡检中心界面与表格工作区改造设计

## 目标

在不改变现有巡检采集方式的前提下，统一美化网络巡检中心，减少页面内堆叠的配置表单，并把全部数据表升级为可按字段筛选、排序、分页和自定义列的独立工作区。

## 已确认范围

- 表格显示列、启用的筛选字段和每页数量保存在当前浏览器，不依赖登录账号。
- 人员、计算机、网络设备、服务器、安防设备、巡检记录和异常记录继续使用现有独立页面。
- 域控主页不再同时展示域账号和域计算机表格；二者拆成独立子页面。
- 域控连接设置使用点击打开的 Bootstrap 弹窗。
- CSV 导入、模板下载和导出入口集中在点击打开的数据工具弹窗。
- 表格筛选、排序、列设置仍在表格主页面，不放入弹窗。
- 本阶段不调整 SSH、Windows HTTP 服务、安防 API 和域控同步的底层安全策略。

## 页面结构

### 全局框架

保留 Bootstrap 和 Django 模板技术栈，不新增前端框架。全局页面采用深色品牌导航、浅色工作区、统一圆角卡片和状态色。导航在桌面端直接展示主要模块，在窄屏端折叠；页面标题区统一包含标题、说明和主要操作。

CSS 使用一组语义化设计变量统一背景、边框、阴影、圆角、主色和状态色。表格工具栏、空状态、分页、按钮和弹窗采用同一视觉规范，并保持键盘焦点可见和移动端横向滚动。

### 首页

首页继续作为全局总览，保留资产统计、最近巡检和最近异常。统计卡片强化正常、异常和未巡检状态层级；全部数据入口明确跳转至对应独立表格页。首页的小型表格只提供快捷查看，不承担完整配置能力。

### 域控工作区

域控主页仅包含：

- 域账号、域计算机、停用对象统计；
- 最近同步或配置概况；
- “同步域控”主要操作；
- “域控连接设置”按钮，打开现有配置表单弹窗；
- “查看域账号”和“查看域计算机”入口。

新增两个独立路由：

- `/domain/accounts/`：域账号表格工作区；
- `/domain/computers/`：域计算机表格工作区。

域账号和域计算机仍只从域控同步，不提供手动导入。两个子页面支持 CSV 导出，但不显示 CSV 导入控件。

### 资产数据工具弹窗

人员、网络设备、服务器、安防设备等允许导入的页面，把当前占据页面空间的上传表单改为“数据工具”弹窗。弹窗包含模板下载、CSV 文件选择、开始导入和导出当前资产按钮。计算机、域账号和域计算机由系统自动获取，只显示导出和来源说明。

## 统一表格工作区

### 字段注册表

服务端维护唯一的表格字段注册表。每个表格字段声明：

- 稳定字段键；
- 中文标签；
- 数据来源或 ORM 字段；
- 显示格式；
- 是否默认显示；
- 是否允许筛选；
- 筛选类型：文本、选项、布尔值、日期或日期范围；
- 是否允许排序。

视图、模板和筛选逻辑均读取该注册表，避免 `MODEL_MAP`、`TABLE_CONFIGS`、模板表头和筛选项分别维护造成不一致。只允许注册表内字段参与查询和排序，防止客户端任意拼接 ORM 字段。

### 动态筛选

每个完整表格页面展示基础关键词搜索，以及用户启用的字段筛选项。文本使用不区分大小写的包含匹配；选项和布尔值使用精确匹配；日期支持单日或起止范围。筛选作用于全部查询集，然后再分页，不局限当前页。

URL 查询参数保存当前查询条件，便于刷新和复制链接。无效字段、无效排序或不合法筛选值被忽略，并回退到注册表默认值。

### 浏览器偏好

新增无依赖 JavaScript 表格控制器，以表格唯一键将以下偏好写入 `localStorage`：

- 可见列；
- 已启用筛选字段；
- 每页条数。

偏好键包含版本号，例如 `inspection-table:v1:computers`。页面加载时读取偏好并控制列显隐、筛选控件显隐及 `page_size` 查询参数。用户可在页面内展开“自定义表格”区域进行勾选并恢复默认值。偏好损坏或字段版本变化时自动忽略未知字段，保证页面仍可使用。

### 表格交互

表头对允许排序的字段显示排序状态，并通过普通 GET 链接触发服务端排序。分页保留筛选、排序和每页数量。每个表格提供结果数量、当前范围和无数据说明。操作列固定在末尾且不参与显示字段设置。

## 计算机信息扩展

### 缓存字段

`Computer` 模型新增最新上报摘要字段，便于全量筛选和排序：

- 登录账号；
- IP 地址；
- MAC 地址；
- 系统主要版本；
- 系统详细版本；
- 系统安装时间；
- 最近开机时间；
- CPU 温度；
- CPU 使用率；
- 内存容量；
- 内存使用率。

这些字段保留 PowerShell 上报的显示文本，避免因采集失败、单位变化或本地化格式导致数据丢失。现有 `os`、`user_name`、`last_report_at` 和 `is_active` 保持兼容。

### 上报更新与历史回填

计算机巡检 API 在保存巡检记录的同一事务内，从“系统信息概览”“网络信息”和“计算机硬件资源情况”提取摘要并更新 `Computer`。网络信息可能包含多个网卡，IP 和 MAC 去空、去重后以逗号连接。

新增幂等管理命令，从每台计算机最新巡检记录回填摘要字段。命令只更新能从历史记录明确提取的值；缺失值保持为空，不制造测试内容。

计算机表格默认展示计算机名、IP、操作系统、当前用户、CPU 使用率、内存使用率、最后上报时间和状态，其余字段由用户在“自定义表格”区域选择。

## 服务端组件边界

- `index/table_registry.py`：表格及字段声明、显示元数据，不处理请求。
- `index/table_query.py`：验证并应用动态筛选、排序、分页参数。
- `index/views.py`：组装页面上下文和业务操作，不重复声明字段规则。
- `index/templates/table_workspace.html`：统一筛选、自定义区域、结果摘要和表格结构。
- `static/js/table_workspace.js`：浏览器偏好与列显隐，不执行服务端数据筛选。
- `net/services/computer_snapshot.py`：从巡检 JSON 提取计算机摘要，供 API 和回填命令复用。

## 错误处理

- 域控配置表单错误在弹窗内显示，返回页面后自动重新打开弹窗。
- CSV 导入失败继续使用页面消息，并在必要时自动打开数据工具弹窗。
- 浏览器禁用或拒绝 `localStorage` 时，表格使用服务端默认列和默认筛选项，不阻断操作。
- 动态筛选只接受注册字段；无效参数回退默认设置，不产生服务器错误。
- 计算机摘要提取容忍缺少节点、非数组网络信息和采集失败文本。

## 测试与验收

开发采用测试先行：先观察新行为测试因功能缺失而失败，再实现最小代码使其通过。

自动化测试覆盖：

- 注册表中的全部允许字段可生成正确筛选定义；
- 文本、选项、布尔和日期范围筛选作用于完整查询集；
- 非注册字段和非法排序被拒绝或安全回退；
- 分页保留查询条件和每页数量；
- 域控主页不渲染两个大表，两个子路由分别返回正确数据；
- 域控设置和 CSV 工具以弹窗触发器呈现；
- 计算机上报正确更新所有可提取摘要；
- 历史回填命令可重复执行且结果一致。

浏览器验收覆盖桌面与窄屏：

- 域控设置弹窗打开、校验错误和成功关闭；
- CSV 工具弹窗及导入表单；
- 表格列显隐、筛选项显隐和刷新后偏好保持；
- 全字段筛选、排序、分页组合；
- 域账号和域计算机子页面跳转；
- 计算机扩展字段展示与长文本溢出处理；
- 控制台无 JavaScript 错误。

## 非目标

- 不引入用户登录或把表格偏好同步到服务器。
- 不新增可视化拖拽排序列顺序。
- 不修改巡检协议、设备凭据保存方式或域控安全策略。
- 不把首页快捷表格改造成完整数据表工作区。
