# 原始设备配置备份实施计划

- [x] 独立加密模型与存储服务：按北京时间每设备每天首次成功保留一份，最近十份；失败不覆盖。
- [x] 网络巡检自动获取当前配置，当天成功后复用；配置仅保存到备份库，普通记录只保留元数据。
- [x] 管理员历史列表、指定版本下载和最新版本 ZIP；原文不脱敏、不添加前缀。
- [x] Web/Worker 共享稳定备份密钥；部署迁移与针对性验证。
- [x] 文档说明恢复边界：Cisco/H3C 当前配置不包括固件、证书私钥；现有大华 Network 局部接口不能作为整机备份。

并行分工：存储服务/模型/迁移、历史页面、旧下载链路分别实施；主任务负责巡检接入、密钥配置和集成验证。所有设备外部调用使用测试替身，不执行设备恢复。

验收：130 项相关测试通过；迁移一致性通过；MariaDB 事务回滚验证原文加密往返、每日去重和 10 份留存；管理员历史列表及下载权限测试通过。独立只读审查未发现 Important/Critical 问题。现场已应用 0041，配置密钥保存在 Windows 凭据管理器，不保留测试资产。安防整机备份待具体型号原生接口支持，未冒充实现。
